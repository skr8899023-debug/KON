# 🗂️ KON — مدير الملفات الذكي

تطبيق ويب مبتكر لـ **تشغيل** و**تعديل** و**تحرير** الملفات من المتصفح مباشرةً، بواجهة عربية كاملة (RTL) وبدون أي اعتماديات خارجية — يعتمد فقط على Node.js المدمج.

![الحالة](https://img.shields.io/badge/Node.js-%3E%3D16-brightgreen) ![الترخيص](https://img.shields.io/badge/license-MIT-blue)

## ✨ الميزات

- **📁 مستكشف ملفات شجري** — تصفّح المجلدات والملفات مع طيّها وتوسيعها.
- **✏️ محرّر نصوص وأكواد** — بأرقام أسطر، دعم مفتاح Tab، وتتبّع التغييرات غير المحفوظة.
- **▶️ تشغيل مباشر** — نفّذ ملفات `JavaScript` · `Python` · `Bash` · `Ruby` · `PHP` وشاهد المخرجات فوراً في لوحة نتائج.
- **🖼️ معاينة الوسائط** — عرض الصور والفيديو والصوت وملفات PDF داخل التطبيق.
- **🗂️ إدارة كاملة** — إنشاء، رفع، إعادة تسمية، حذف، وتنزيل الملفات والمجلدات.
- **🔍 بحث فوري** — في أسماء الملفات وداخل محتواها.
- **🖱️ قائمة سياق** بالنقر الأيمن، وتبويبات متعددة، وسمة فاتحة/داكنة.
- **⌨️ اختصارات** — `Ctrl+S` للحفظ، `Ctrl+Enter` للتشغيل.
- **🔒 آمن** — كل العمليات محصورة داخل مجلد `workspace` مع حماية من تجاوز المسارات (path traversal).

## 🚀 التشغيل

```bash
node server.js
# أو
npm start
```

ثم افتح المتصفح على: <http://localhost:3000>

### خيارات

```bash
node server.js --port 8080 --root ./my-files
```

| الخيار | الوصف | الافتراضي |
|--------|-------|-----------|
| `--port` | منفذ الخادم | `3000` |
| `--root` | مجلد العمل | `./workspace` |

## 🧱 البنية

```
KON/
├── server.js        # الخادم (HTTP API + خدمة الملفات) — بلا اعتماديات
├── package.json
├── public/          # الواجهة الأمامية
│   ├── index.html
│   ├── styles.css
│   └── app.js
└── workspace/       # مجلد العمل (ملفاتك)
```

## 🔌 واجهة الـ API

| المسار | الطريقة | الوصف |
|--------|---------|-------|
| `/api/tree` | GET | شجرة الملفات |
| `/api/file?path=` | GET | قراءة ملف نصي |
| `/api/file` | POST | حفظ/إنشاء ملف |
| `/api/raw?path=` | GET | المحتوى الخام (للمعاينة) |
| `/api/download?path=` | GET | تنزيل ملف |
| `/api/run` | POST | تشغيل ملف |
| `/api/search?q=` | GET | البحث |
| `/api/mkdir` · `/api/rename` · `/api/delete` · `/api/upload` | POST | إدارة الملفات |

## 🔒 ملاحظات الأمان

- جميع مسارات الملفات تُقيَّد داخل مجلد `workspace` فقط.
- تشغيل السكربتات محدود بمهلة زمنية (15 ثانية) وحجم مخرجات أقصى.
- التطبيق مخصّص للاستخدام المحلي/الموثوق؛ لا تعرّضه للإنترنت العام دون طبقة مصادقة.
