# 🗂️ KON — مدير الملفات الذكي

تطبيق ويب مبتكر لـ **تشغيل** و**تعديل** و**تحرير** الملفات من المتصفح مباشرةً، بواجهة عربية كاملة (RTL) وبدون أي اعتماديات خارجية — يعتمد فقط على Node.js المدمج.

![الحالة](https://img.shields.io/badge/Node.js-%3E%3D16-brightgreen) ![الترخيص](https://img.shields.io/badge/license-MIT-blue)

## ✨ الميزات

- **🎼 استوديو موسيقى لملفات MIDI** — فتح وتشغيل `.mid/.midi` بمحرك Web Audio، عرض النوتات على Piano Roll قابل للتحرير (إضافة/حذف بالنقر)، **مصفوفة إيقاعات** بسبع آلات (كيك، سنير، هاي هات، تصفيق، توم، دفّ) لإضافة ضرباتك، وتصدير النتيجة ملف MIDI جديداً. راجع القسم أدناه.
- **🥁 مفتّش ومحرّر ملفات Kontakt (`.nkm` / `.nki`)** — تحليل تنسيق Native Instruments FileContainer وعرض بنيته وبياناته الوصفية وسكربتات Kontakt (KSP)، مع تحرير آمن. راجع القسم أدناه.
- **📁 مستكشف ملفات شجري** — تصفّح المجلدات والملفات مع طيّها وتوسيعها.
- **✏️ محرّر نصوص وأكواد** — بأرقام أسطر، دعم مفتاح Tab، وتتبّع التغييرات غير المحفوظة.
- **▶️ تشغيل مباشر** — نفّذ ملفات `JavaScript` · `Python` · `Bash` · `Ruby` · `PHP` وشاهد المخرجات فوراً في لوحة نتائج.
- **🖼️ معاينة الوسائط** — عرض الصور والفيديو والصوت وملفات PDF داخل التطبيق.
- **🗂️ إدارة كاملة** — إنشاء، رفع، إعادة تسمية، حذف، وتنزيل الملفات والمجلدات.
- **🔍 بحث فوري** — في أسماء الملفات وداخل محتواها.
- **🖱️ قائمة سياق** بالنقر الأيمن، وتبويبات متعددة، وسمة فاتحة/داكنة.
- **⌨️ اختصارات** — `Ctrl+S` للحفظ، `Ctrl+Enter` للتشغيل.
- **🔒 آمن** — كل العمليات محصورة داخل مجلد `workspace` مع حماية من تجاوز المسارات (path traversal).

## 🎼 استوديو الموسيقى (MIDI)

عند فتح أي ملف `.mid`/`.midi` تظهر واجهة الاستوديو:

- **شريط النقل**: تشغيل/إيقاف، تعديل سرعة الإيقاع (BPM)، تكرار حلقي، وتصدير.
- **Piano Roll**: كل النوتات ملوّنة حسب المسار، مع مؤشر تشغيل حيّ. انقر خلية فارغة لإضافة نوتة، وانقر نوتة لحذفها. انقر شريحة مسار لكتمه.
- **مصفوفة الإيقاعات**: 9 آلات مُخلّقة بمحرك Web Audio (كيك 🦶، سنير 🥁، هاي هات مغلق/مفتوح 🎩، تصفيق 👏، توم 🪘، دفّ 🪘، طار حاد/غليظ 🪘) — فعّل الخطوات لإضافة ضرباتك فوق الملف الأصلي، واستمع لكل آلة بالنقر على اسمها.
- **🎹 أصوات المفاتيح**: لكل مفتاح/نوتة في الملف قائمة اختيار — اجعله يعزف بأي آلة مدمجة أو **بعيّنة صوتية خارجية**. النقر على تسمية المفتاح في Piano Roll يعاين صوته الحالي. الخريطة تُحفظ تلقائياً (localStorage) لكل ملف.
- **⬆ استيراد أصوات خارجية**: ارفع ملفات `WAV / MP3 / OGG / FLAC / M4A` من زر "استيراد صوت خارجي" — تُخزَّن في `workspace/samples/` وتظهر فوراً في قوائم أصوات المفاتيح، وتُحمَّل وتُشغَّل بمحرك Web Audio أثناء العزف.
- **دعم الميزان الموسيقي**: 3/4 و4/4 وغيرهما — الشبكة والحلقة والبارات تُحاذى على الميزان الفعلي للملف، مع عدّاد موضع حيّ (بار : ضربة) وتحكّم بمستوى الصوت.
- **التصدير**: يبني ملف MIDI جديداً يضم المسارات الأصلية (مع تعديلاتك) + مسار "KON Rhythm" على قناة الطبول (10) بنغمات General MIDI.
- **فتح مباشر بالرابط**: `http://localhost:3000/#open=midi/اسم_الملف.midi`

> ملفات الإيقاع الشرقي التجريبية في `workspace/midi/`: Janoobi (164 BPM · 753 نوتة) وAtbah (180 BPM · وصلة بار واحد).

## 🥁 مفتّش ملفات Kontakt (`.nkm` / `.nki`)

ملفات `.nkm` (أطقم Multi) و`.nki` (آلات Instrument) من Native Instruments بتنسيق **FileContainer** الثنائي المغلق. عند فتح أيٍّ منها في KON يظهر **مفتّش متخصّص** بأربعة أقسام:

| القسم | المحتوى |
|-------|---------|
| **📋 معلومات** | التنسيق، اسم الآلة/الطقم، نوع المحتوى، إصدار Kontakt، حجم الملف والحجم المعلن، المعرّف `GUID`، عدّاد الحاويات (`hsin`/`DSIN`/`4KIN`)، القالب، المؤلف/المصدر، وعنوان السكربت. |
| **🧩 الحاويات** | خريطة كل حاويات NI FileContainer مع إزاحاتها وقيمها المجاورة. |
| **🔤 النصوص والسكربت** | استخراج سكربت Kontakt (KSP) وكل السلاسل النصية المقروءة، مع تصفية فورية وتحرير. |
| **🔢 Hex** | عارض/متصفّح hex لأي إزاحة في الملف. |

**التحرير الآمن:** يدعم KON استبدال السلاسل النصية **بنفس الطول تماماً** (للحفاظ على سلامة التنسيق الثنائي)، ويأخذ **نسخة احتياطية تلقائية** (`.bak`) قبل أي كتابة. أي محاولة تعديل بطول مختلف أو خارج حدود الملف تُرفض.

> ⚠️ التنسيق مغلق المصدر من Native Instruments؛ المحلّل يعمل بأفضل جهد (best-effort) للفحص والتحرير الآمن. لا يقوم بإعادة توليد بيانات العيّنات المضغوطة أو بفكّ ترميز KSP كاملاً.

## 🚀 التشغيل

```bash
node server.js
# أو
npm start
```

ثم افتح المتصفح على: <http://localhost:3000>

### خيارات

```bash
node server.js --port 8080 --root ./my-files
```

| الخيار | الوصف | الافتراضي |
|--------|-------|-----------|
| `--port` | منفذ الخادم | `3000` |
| `--root` | مجلد العمل | `./workspace` |

## 🧱 البنية

```
KON/
├── server.js        # الخادم (HTTP API + خدمة الملفات) — بلا اعتماديات
├── nkm.js           # محلّل ومحرّر حاويات NI (.nkm / .nki)
├── package.json
├── public/          # الواجهة الأمامية
│   ├── index.html
│   ├── styles.css
│   ├── app.js       # إدارة الملفات + مفتّش Kontakt
│   ├── midi.js      # محلّل وباني ملفات MIDI (SMF)
│   └── studio.js    # استوديو الموسيقى (تشغيل + Piano Roll + إيقاعات)
└── workspace/       # مجلد العمل (ملفاتك)
    ├── kits/        # أطقم .nkm تجريبية
    ├── instruments/ # آلات .nki تجريبية (Merjaf)
    └── midi/        # إيقاعات MIDI تجريبية (Janoobi · Atbah)
```

## 🔌 واجهة الـ API

| المسار | الطريقة | الوصف |
|--------|---------|-------|
| `/api/tree` | GET | شجرة الملفات |
| `/api/file?path=` | GET | قراءة ملف نصي |
| `/api/file` | POST | حفظ/إنشاء ملف |
| `/api/raw?path=` | GET | المحتوى الخام (للمعاينة) |
| `/api/download?path=` | GET | تنزيل ملف |
| `/api/run` | POST | تشغيل ملف |
| `/api/search?q=` | GET | البحث |
| `/api/mkdir` · `/api/rename` · `/api/delete` · `/api/upload` | POST | إدارة الملفات |
| `/api/nkm?path=` | GET | تحليل ملف `.nkm` (بنية + بيانات وصفية + سلاسل + سكربت) |
| `/api/nkm/hex?path=&offset=&length=` | GET | مقطع hex من ملف `.nkm` |
| `/api/nkm/patch` | POST | تعديل بايتات/استبدال نص بنفس الطول (مع نسخة `.bak`) |

## 🔒 ملاحظات الأمان

- جميع مسارات الملفات تُقيَّد داخل مجلد `workspace` فقط.
- تشغيل السكربتات محدود بمهلة زمنية (15 ثانية) وحجم مخرجات أقصى.
- التطبيق مخصّص للاستخدام المحلي/الموثوق؛ لا تعرّضه للإنترنت العام دون طبقة مصادقة.
